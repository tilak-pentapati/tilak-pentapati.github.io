Introduction & Overview

Residential mobility—how frequently individuals and households relocate—is closely intertwined with labour market structure, socioeconomic status, and life-course dynamics. Higher-skilled professionals often participate in national or regional labour markets that reward geographic flexibility and career-driven relocation, whereas lower-skilled and routine occupations are more frequently anchored to local labour markets and longer-term residential stability.

This notebook reconstructs and documents the empirical analysis submitted for ENVS450 (Social Survey Analysis) coursework at the Department of Geography and Planning, School of Environmental Sciences, University of Liverpool (Module Leader: Dr. Paul Williamson). The study investigates a core empirical question:

Research Question: Does occupational skill level, as measured by the UK Office for National Statistics (ONS) Standard Occupational Classification (SOC 2020), relate to how long individuals have resided at their current address (Address_Duration) in the 2021 Annual Population Survey (APS)?

0.0.1 Dataset Overview

The analysis uses the Annual Population Survey (APS) 2021 teaching extract (APS), which comprises N = 249,997 individual survey respondents across 60 demographic, socioeconomic, and housing variables, accompanied by a structured variable dictionary (meta_data) and UK Mid-Year Population Estimates (MYE_UK_wide) across seven age bands.

The analytical workflow proceeds through seven stages:

  1. Univariate Description & Recoding: Collapsing the 28-category nominal SOC_Sub_Major variable into 4 ordinal ONS occupational skill levels (L1–L4) and the 8-category ordinal Address_Duration variable into 4 duration intervals (0-2 Years, 2-5 Years, 5-10 Years, 10 years or longer), evaluating central tendency via the Median and categorical dispersion via the Standardised Reciprocal Diversity Index (SRDI).
  2. Bivariate Cross-Tabulation: Examining conditional row percentages in both directions (N = 108,964 complete cases) to distinguish how residential tenure distributes within skill levels versus how occupational skill levels compose each tenure band.
  3. Graphical Visualisation: Constructing 100% stacked bar charts with exact percentage annotations to visualise the bivariate distributions.
  4. Statistical Significance Testing: Testing the null hypothesis of statistical independence in the population using Pearson’s Chi-Square (\chi^2) test and evaluating substantive effect size via Cramér’s V.
  5. Quantifying Random Sampling Error: Computing 95% Confidence Intervals (CIs) for every cell percentage to assess sampling precision.
  6. Addressing Non-Random Response Bias: Implementing post-stratification survey reweighting calibrated against ONS Mid-Year Population Estimates by age group (Age_Count_Ratio) and comparing the results against both unweighted estimates and official ONS survey weights (Weight_APS).
  7. Multivariate Extension (Subgroup Analysis): Discretising numeric household size (Hhold_Size) into tertiles (Low, Medium, High) to test whether household composition moderates the relationship between occupational skill level and residential tenure.

NoteTechnical Definition: Standardised Reciprocal Diversity Index (SRDI)

For a categorical variable with K categories and observed category frequencies f_1, f_2, \dots, f_K summing to N = \sum_{i=1}^{K} f_i, let p_i = \frac{f_i}{N} denote the proportion of observations in category i.

The Reciprocal Diversity Index (RDI) (also known in ecology and economics as the inverse Simpson or Herfindahl–Hirschman reciprocal index) is defined as:

\text{RDI} = \frac{1}{\sum_{i=1}^{K} p_i^2}

Because \text{RDI} ranges from 1 (complete concentration in a single category) to K (uniform distribution across all K categories where p_i = 1/K), the Standardised Reciprocal Diversity Index (SRDI) rescales \text{RDI} onto a 0\text{--}100 scale to allow comparison across variables with different numbers of categories:

\text{SRDI} = \left( \frac{\text{RDI} - 1}{K - 1} \right) \times 100

  • \text{SRDI} = 0: Zero diversity (all observations fall into a single category).
  • \text{SRDI} = 100: Maximum diversity (observations are equally distributed across all K categories).
Code 
# Define the Standardised Reciprocal Diversity Index (SRDI) function
# (Originally sourced from functions_R/SRDI_function.R in the ENVS450 course workspace)
SRDI <- function(x, na.rm = TRUE) {
  # Check that the variable supplied is categorical
  if (!is.factor(x) & !is.character(x)) {
    stop("Error: IQV can only be calculated for categorical variables")
  }

  # If removal of NA values requested, drop NA values from x
  if (na.rm == TRUE) {
    x <- x[!is.na(x)]
  }

  # If inclusion of NA values requested, convert NA values to level
  if (na.rm == FALSE) {
    x <- fct_na_value_to_level(x, level = NA)
  }

  # Convert supplied variable to a factor if necessary
  if (!is.factor(x)) {
    x <- factor(x)
  }

  # Find the number of categories (K) in the resulting factor variable
  K <- length(levels(x))

  # Find the frequency distribution, including for empty categories
  f <- table(x)

  # Calculate the squared proportions of these frequencies
  # [some people call this Simpson's Index of Diversity;
  #  Agresti calls 1 - p_sq Simpson's Index of Diversity]
  p_sq <- (f / sum(f))^2

  # Calculate the Reciprocal Diversity Index
  RDI <- 1 / sum(p_sq)

  # Calculate the standardised RDI (rescaled to range 0 to 100)
  SRDI_val <- (RDI - 1) / (K - 1) * 100

  return(SRDI_val)
}

2 Univariate Description & Recoding of Variables

NoteLevels of Measurement & Appropriate Summary Statistics
  • Nominal categorical variables (such as the 28 occupational sub-major groups in SOC_Sub_Major) classify observations into qualitative categories without an intrinsic rank order.
  • Ordinal categorical variables (such as occupational skill level L1 < L2 < L3 < L4 or Address_Duration intervals) possess a meaningful rank order across categories, though the numerical distance between adjacent categories is not constant.
  • For ordinal variables, the Median (the category containing the 50\text{th} percentile of ranked observations) is the appropriate measure of central tendency, while the SRDI measures categorical dispersion across levels.

2.1 Standard Occupational Classification (SOC 2020) Sub-Major Group

In the raw APS 2021 extract, SOC_Sub_Major is a nominal categorical variable with 28 levels (26 substantive occupational sub-major groups plus "Does not apply" and "No answer"). Each category represents a grouping of job titles and occupational roles.

2.1.1 Rationale and Recoding into ONS Skill Levels

Following the official Office for National Statistics (ONS, 2023) SOC 2020 Volume 1 taxonomy, occupational groups are structured around the concept of Skill Level—defined by the duration of formal education, training, and work experience required for competent performance of the job tasks. We reclassify the 26 occupational sub-major groups into 4 ordinal skill levels (L1 through L4 in ascending order of skill), while mapping "Does not apply" and "No answer" to "Ineligible or unknown" and converting that level to NA:

  • Level 1 (L1 — Elementary occupations): Competence associated with compulsory general education and short periods of on-the-job induction (2 sub-major groups).
  • Level 2 (L2 — Administrative, caring, sales, and operative occupations): Competence requiring general education typically up to GCSE/O-level standard plus longer periods of work-related training or experience (9 sub-major groups).
  • Level 3 (L3 — Associate professional and skilled trade occupations): Competence requiring post-compulsory education (A-levels, vocational awards, apprenticeships) or substantial technical experience (10 sub-major groups).
  • Level 4 (L4 — Professional and higher managerial occupations): Competence requiring a degree-level qualification or equivalent extensive professional experience (5 sub-major groups).

Transforming SOC_Sub_Major from a 28-level nominal variable into a 4-level ordered factor (L1 < L2 < L3 < L4) reduces table sparsity and enables direct ordinal testing of whether higher occupational skill levels are associated with greater residential mobility.

2.2 Length of Time at Current Address (Address Duration)

The Address_Duration variable records how long each respondent has lived at their current residential address. In the raw APS extract, it is an ordinal categorical variable with 8 levels (6 duration bands plus "Does not apply" and "No answer").

2.2.1 Rationale and Recoding into 4 Duration Intervals

Before reclassification, the 8-level raw variable has a very low dispersion index (\text{SRDI} = 32.81) because nearly half of all respondents are concentrated in the "10 years or longer" category while the shorter duration categories ("Less than 12 months", "12 months, less than 24", "2 years, less than 3", "3 years, less than 5") each hold relatively small proportions. Retaining fine-grained short intervals alongside a massive 10+ year category can produce sparse cells in multi-way cross-tabulations.

We therefore collapse the valid responses into 4 ordinal duration intervals:

  • 0-2 Years: "Less than 12 months" and "12 months, less than 24" (recent movers).
  • 2-5 Years: "2 years, less than 3" and "3 years, less than 5" (short-to-medium tenure).
  • 5-10 Years: "5 years, less than 10" (medium-to-long tenure).
  • 10 years or longer (10-Inf): "10 years or longer" (long-term settled residents).
  • Missing (NA): "Does not apply" and "No answer" mapped to "Ineligible or unknown" and converted to NA.

NoteConditional Distributions in Contingency Tables

A two-way contingency table of an R \times C categorical relationship can be normalised in two complementary ways:

  1. Row percentages conditioned on SOC Skill Level (P(\text{Address Duration} \mid \text{Skill Level})): Shows how length of residence is distributed within each occupational skill group (Table 1). Each skill-level row sums to 100\%.

Excluding observations with NA on either variable yields an analytical sample of N = 108,964 employed/classified respondents with valid residential duration records.

3.3 Discussion of Bivariate Patterns

5 Statistical Significance Testing (Chi-Square Test)

While the sample cross-tabulations and stacked bar charts show a clear pattern linking higher occupational skill levels with shorter residential durations, we must test whether this observed association could have arisen purely from random sampling error when drawing the APS sample from the UK population.

NotePearson’s Chi-Square (\chi^2) Test of Independence

To test whether two categorical variables with r rows and c columns are statistically independent in the population, we specify:

  • Null Hypothesis (H_0): There is no association between SOC Skill Level and Address Duration in the population (the variables are statistically independent).
  • Alternative Hypothesis (H_1): There is an association between SOC Skill Level and Address Duration in the population.

Under H_0, the expected frequency E_{ij} in cell (i, j) is determined by the product of the row marginal total R_i and column marginal total C_j divided by the grand total N:

E_{ij} = \frac{R_i \times C_j}{N}

The Pearson Chi-Square test statistic sums the squared standardised residuals across all r \times c cells:

\chi^2 = \sum_{i=1}^{r} \sum_{j=1}^{c} \frac{(O_{ij} - E_{ij})^2}{E_{ij}}

Under H_0, \chi^2 asymptotically follows a \chi^2 distribution with degrees of freedom:

df = (r - 1)(c - 1) = (4 - 1)(4 - 1) = 9

5.0.1 Interpretation of the Chi-Square Test

The test yields \chi^2 = 637.8 with df = 9 and p < 2.2 \times 10^{-16}. Because the p-value is far below any conventional significance threshold (\alpha = 0.05 or \alpha = 0.001), we reject the null hypothesis (H_0) and conclude that there is a statistically significant association between SOC Skill Level and Address Duration in the UK population.

WarningLooking Back / Methodological Reflection: Interpreting p < 2.2 \times 10^{-16} vs. Effect Size

In the original submitted report (page 8), the output p-value < 2.2e-16 was interpreted literally as: “if there is [no] association between SOC Skill Level and Address Duration in the population, then there is only one in 2.2 quintillion chance of having random sampling error leading to a relationship… Finally, it tends to be ‘There is strong association between SOC Skill Level and Address Duration in the Population’.”

Two important statistical clarifications apply here:

  1. Machine Precision Limit (.Machine$double.eps): R prints < 2.2e-16 because 2.22 \times 10^{-16} is the floating-point machine epsilon (2^{-52}) in IEEE 754 double-precision arithmetic. The exact analytical p-value for \chi^2 = 637.8 with df = 9 is actually on the order of 10^{-131}, rather than literally 1 / (2.2 \times 10^{18}).
  2. Statistical Significance vs. Substantive Strength (Effect Size): Because \chi^2 scales linearly with sample size N, a sample of N = 108,964 will produce an overwhelmingly small p-value even for modest departures from independence. A small p-value proves that the relationship is not due to chance, but does not by itself prove that the association is strong. Measuring the effect size via Cramér’s V: V = \sqrt{\frac{\chi^2}{N \cdot \min(r-1, c-1)}} = \sqrt{\frac{637.8}{108,964 \times 3}} \approx 0.0442 shows a statistically rock-solid but modest effect size (V \approx 0.044, representing a 10.6 percentage-point spread in 10+ year tenure between L1 and L4).

6 Quantifying Random Sampling Error (Confidence Intervals)

Because survey percentages are sample estimates of unknown population parameters, each cell percentage is subject to random sampling variability. We quantify the precision of every cell percentage in Tables 1 and 2 by computing 95% Confidence Intervals (CIs).

NoteStandard Error and 95% Confidence Interval for a Sample Percentage

For a sample percentage p \in [0, 100] estimated from a subgroup of sample size n, the Standard Error (\text{SE}) under simple random sampling is:

\text{SE}(p) = \sqrt{\frac{p(100 - p)}{n}}

Using the normal approximation (z_{0.975} = 1.96), the 95% Confidence Interval is:

\text{CI}_{95\%} = p \pm 1.96 \times \sqrt{\frac{p(100 - p)}{n}}

Rather than repeating manual column-by-column calculations eight times, we define a concise helper function calc_ci_table() that computes the standard error and formats the 95% confidence interval [lower - upper] for any percentage matrix and row sample size vector:

Code 
calc_ci_table <- function(pct_matrix, n_vector) {
  # pct_matrix: matrix of percentages (0-100)
  # n_vector: sample size per row
  se_matrix <- sqrt((pct_matrix * (100 - pct_matrix)) / n_vector)
  lower <- pmax(0, pct_matrix - 1.96 * se_matrix)
  upper <- pmin(100, pct_matrix + 1.96 * se_matrix)

  # Format as "[lower - upper]"
  formatted <- matrix(
    sprintf("[%.1f - %.1f]", lower, upper),
    nrow = nrow(pct_matrix),
    dimnames = dimnames(pct_matrix)
  )
  return(as.data.frame(formatted))
}

6.2.2 2. Frequentist Interpretation of Confidence Intervals

In the original report (page 9), the 95% CI was first correctly introduced (“sample estimate will be population representative in 95 out of every 100 samples”), followed by the phrasing “there is probability of 0.95 that % of people staying for 10 or more years who has SOC Skill Level L2 in the population lies within the range of 33.1% to 33.9%.”

In strict frequentist inference, the true population parameter \pi is a fixed (non-random) constant, while the interval endpoints are random variables across repeated samples. Thus, a 95% CI means that if we repeated the survey sampling procedure many times, 95% of the resulting confidence intervals would contain the true population percentage. Regardless of phrasing, because the subgroup sample sizes are large (n \ge 9,486), the confidence intervals in Tables 3 and 4 are narrow (\pm 0.4\% to \pm 1.0\%) and non-overlapping across key skill categories, confirming that the observed differences between L1–L2 and L4 cannot be attributed to random sampling error.

7 Addressing Non-Random Response Bias & Missing Data (Post-Stratification Reweighting)

Confidence intervals and Chi-Square tests only account for random sampling error. In real-world social surveys, however, sample estimates can also be distorted by non-random response bias (systematic differential non-response across demographic groups) and missing data. For instance, younger adults and mobile renters are typically harder to contact and less likely to respond to household surveys than older, settled homeowners.

Two primary strategies exist to address missingness and non-response bias:

  1. Imputation or deletion for item missingness (such as complete-case filtering when NA corresponds to structurally inapplicable respondents like children or retirees).
  2. Post-stratification survey reweighting to correct for unit non-response and sample under-/over-representation relative to known population totals from census or official demographic registers.
NotePost-Stratification Weighting Formula

Given an external population benchmark (here, the ONS Mid-Year Population Estimates MYE_UK_wide) across G mutually exclusive age strata (g = 1, \dots, G), let:

  • \text{MYE\_Count}_g: True population count in age group g.
  • \text{APS\_Count}_g: Observed survey sample count in age group g.

The grossing-up post-stratification weight (or age count ratio) for each respondent in age group g is:

w_g = \text{Age\_Count\_Ratio}_g = \frac{\text{MYE\_Count}_g}{\text{APS\_Count}_g}

Equivalently, a normalised relative weight is the ratio of the population proportion to the sample proportion: w_g^{\text{rel}} = \frac{\text{MYE\_Pct}_g}{\text{APS\_Pct}_g}. Applying w_g scales the sample up to the total UK population while simultaneously correcting the age distribution so that weighted sample proportions exactly match ONS population benchmarks.

# Introduction & Overview {.unnumbered}

Residential mobility—how frequently individuals and households relocate—is closely intertwined with labour market structure, socioeconomic status, and life-course dynamics. Higher-skilled professionals often participate in national or regional labour markets that reward geographic flexibility and career-driven relocation, whereas lower-skilled and routine occupations are more frequently anchored to local labour markets and longer-term residential stability.

This notebook reconstructs and documents the empirical analysis submitted for **ENVS450 (Social Survey Analysis) coursework** at the Department of Geography and Planning, School of Environmental Sciences, University of Liverpool (Module Leader: Dr. Paul Williamson). > **Research Question:** *Does occupational skill level, as measured by the UK Office for National Statistics (ONS) Standard Occupational Classification (SOC 2020), relate to how long individuals have resided at their current address (`Address_Duration`) in the 2021 Annual Population Survey (APS)?*

### Dataset Overview

The analysis uses the **Annual Population Survey (APS) 2021** teaching extract (`APS`), which comprises **$N = 249,997$ individual survey respondents** across **$60$ demographic, socioeconomic, and housing variables**, accompanied by a structured variable dictionary (`meta_data`) and UK Mid-Year Population Estimates (`MYE_UK_wide`) across seven age bands.

2. **Bivariate Cross-Tabulation:** Examining conditional row percentages in both directions ($N = 108,964$ complete cases) to distinguish how residential tenure distributes within skill levels versus how occupational skill levels compose each tenure band.
3. **Graphical Visualisation:** Constructing 100% stacked bar charts with exact percentage annotations to visualise the bivariate distributions.
4. **Statistical Significance Testing:** Testing the null hypothesis of statistical independence in the population using **Pearson's Chi-Square ($\chi^2$) test** and evaluating substantive effect size via **Cramér's $V$**.
5. **Quantifying Random Sampling Error:** Computing **95% Confidence Intervals (CIs)** for every cell percentage to assess sampling precision.
6. **Addressing Non-Random Response Bias:** Implementing **post-stratification survey reweighting** calibrated against ONS Mid-Year Population Estimates by age group (`Age_Count_Ratio`) and comparing the results against both unweighted estimates and official ONS survey weights (`Weight_APS`).
7. **Multivariate Extension (Subgroup Analysis):** Discretising numeric household size (`Hhold_Size`) into tertiles (`Low`, `Medium`, `High`) to test whether household composition moderates the relationship between occupational skill level and residential tenure.

::: {.callout-note}
## Technical Definition: Standardised Reciprocal Diversity Index (SRDI)

For a categorical variable with $K$ categories and observed category frequencies $f_1, f_2, \dots, f_K$ summing to $N = \sum_{i=1}^{K} f_i$, let $p_i = \frac{f_i}{N}$ denote the proportion of observations in category $i$.

The **Reciprocal Diversity Index (RDI)** (also known in ecology and economics as the inverse Simpson or Herfindahl–Hirschman reciprocal index) is defined as:

$$\text{RDI} = \frac{1}{\sum_{i=1}^{K} p_i^2}$$

Because $\text{RDI}$ ranges from $1$ (complete concentration in a single category) to $K$ (uniform distribution across all $K$ categories where $p_i = 1/K$), the **Standardised Reciprocal Diversity Index (SRDI)** rescales $\text{RDI}$ onto a $0\text{--}100$ scale to allow comparison across variables with different numbers of categories:

$$\text{SRDI} = \left( \frac{\text{RDI} - 1}{K - 1} \right) \times 100$$

- $\text{SRDI} = 0$: Zero diversity (all observations fall into a single category).
- $\text{SRDI} = 100$: Maximum diversity (observations are equally distributed across all $K$ categories).
:::

```{r}
#| label: define-srdi

# Define the Standardised Reciprocal Diversity Index (SRDI) function
# (Originally sourced from functions_R/SRDI_function.R in the ENVS450 course workspace)
SRDI <- function(x, na.rm = TRUE) {
  # Check that the variable supplied is categorical
  if (!is.factor(x) & !is.character(x)) {
    stop("Error: IQV can only be calculated for categorical variables")
  }

  # If removal of NA values requested, drop NA values from x
  if (na.rm == TRUE) {
    x <- x[!is.na(x)]
  }

  # If inclusion of NA values requested, convert NA values to level
  if (na.rm == FALSE) {
    x <- fct_na_value_to_level(x, level = NA)
  }

  # Convert supplied variable to a factor if necessary
  if (!is.factor(x)) {
    x <- factor(x)
  }

  # Find the number of categories (K) in the resulting factor variable
  K <- length(levels(x))

  # Find the frequency distribution, including for empty categories
  f <- table(x)

  # Calculate the squared proportions of these frequencies
  # [some people call this Simpson's Index of Diversity;
  #  Agresti calls 1 - p_sq Simpson's Index of Diversity]
  p_sq <- (f / sum(f))^2

  # Calculate the Reciprocal Diversity Index
  RDI <- 1 / sum(p_sq)

  # Calculate the standardised RDI (rescaled to range 0 to 100)
  SRDI_val <- (RDI - 1) / (K - 1) * 100

  return(SRDI_val)
}
```

- **Nominal categorical variables** (such as the 28 occupational sub-major groups in `SOC_Sub_Major`) classify observations into qualitative categories without an intrinsic rank order.

# Statistical Significance Testing (Chi-Square Test)

While the sample cross-tabulations and stacked bar charts show a clear pattern linking higher occupational skill levels with shorter residential durations, we must test whether this observed association could have arisen purely from **random sampling error** when drawing the APS sample from the UK population.

::: {.callout-note}
## Pearson's Chi-Square ($\chi^2$) Test of Independence

To test whether two categorical variables with $r$ rows and $c$ columns are statistically independent in the population, we specify:

- **Null Hypothesis ($H_0$):** There is **no association** between SOC Skill Level and Address Duration in the population (the variables are statistically independent).
- **Alternative Hypothesis ($H_1$):** There **is an association** between SOC Skill Level and Address Duration in the population.

Under $H_0$, the expected frequency $E_{ij}$ in cell $(i, j)$ is determined by the product of the row marginal total $R_i$ and column marginal total $C_j$ divided by the grand total $N$:

$$E_{ij} = \frac{R_i \times C_j}{N}$$

The **Pearson Chi-Square test statistic** sums the squared standardised residuals across all $r \times c$ cells:

$$\chi^2 = \sum_{i=1}^{r} \sum_{j=1}^{c} \frac{(O_{ij} - E_{ij})^2}{E_{ij}}$$

Under $H_0$, $\chi^2$ asymptotically follows a $\chi^2$ distribution with degrees of freedom:

$$df = (r - 1)(c - 1) = (4 - 1)(4 - 1) = 9$$
:::

```{r}
#| label: chi-square-test

# Contingency table of raw counts (4 x 4)
table1 <- tally(
  SOC_Skill_Level_order_NA ~ Address_Duration_recode_NA,
  data = APScopy, na.rm = TRUE
)

# Perform Pearson's Chi-squared test of independence
chi_res <- chisq.test(table1)
chi_res

# Compute Cramér's V to measure effect size (substantive strength of association)
n_total <- sum(table1)
min_dim <- min(nrow(table1) - 1, ncol(table1) - 1)
cramers_v <- sqrt(as.numeric(chi_res$statistic) / (n_total * min_dim))
cat("Cramér's V effect size:", round(cramers_v, 4), "\n")
```

### Interpretation of the Chi-Square Test

The test yields **$\chi^2 = 637.8$** with **$df = 9$** and **$p < 2.2 \times 10^{-16}$**. Because the $p$-value is far below any conventional significance threshold ($\alpha = 0.05$ or $\alpha = 0.001$), we **reject the null hypothesis ($H_0$)** and conclude that there is a **statistically significant association** between SOC Skill Level and Address Duration in the UK population.

::: {.callout-warning}
## Looking Back / Methodological Reflection: Interpreting $p < 2.2 \times 10^{-16}$ vs. Effect Size

In the original submitted report (page 8), the output `p-value < 2.2e-16` was interpreted literally as: *"if there is [no] association between SOC Skill Level and Address Duration in the population, then there is only one in 2.2 quintillion chance of having random sampling error leading to a relationship... Finally, it tends to be 'There is strong association between SOC Skill Level and Address Duration in the Population'."*

Two important statistical clarifications apply here:

1. **Machine Precision Limit (`.Machine$double.eps`):** R prints `< 2.2e-16` because $2.22 \times 10^{-16}$ is the floating-point machine epsilon ($2^{-52}$) in IEEE 754 double-precision arithmetic. The exact analytical $p$-value for $\chi^2 = 637.8$ with $df = 9$ is actually on the order of $10^{-131}$, rather than literally $1 / (2.2 \times 10^{18})$.
2. **Statistical Significance vs. Substantive Strength (Effect Size):** Because $\chi^2$ scales linearly with sample size $N$, a sample of $N = 108,964$ will produce an overwhelmingly small $p$-value even for modest departures from independence. A small $p$-value proves that the relationship is **not due to chance**, but does not by itself prove that the association is *strong*. Measuring the effect size via **Cramér's $V$**:
   $$V = \sqrt{\frac{\chi^2}{N \cdot \min(r-1, c-1)}} = \sqrt{\frac{637.8}{108,964 \times 3}} \approx 0.0442$$
   shows a **statistically rock-solid but modest effect size** ($V \approx 0.044$, representing a $10.6$ percentage-point spread in $10+$ year tenure between `L1` and `L4`).
:::

# Quantifying Random Sampling Error (Confidence Intervals)

Because survey percentages are sample estimates of unknown population parameters, each cell percentage is subject to **random sampling variability**. We quantify the precision of every cell percentage in Tables 1 and 2 by computing **95% Confidence Intervals (CIs)**.

::: {.callout-note}
## Standard Error and 95% Confidence Interval for a Sample Percentage

For a sample percentage $p \in [0, 100]$ estimated from a subgroup of sample size $n$, the **Standard Error ($\text{SE}$)** under simple random sampling is:

$$\text{SE}(p) = \sqrt{\frac{p(100 - p)}{n}}$$

Using the normal approximation ($z_{0.975} = 1.96$), the **95% Confidence Interval** is:

$$\text{CI}_{95\%} = p \pm 1.96 \times \sqrt{\frac{p(100 - p)}{n}}$$
:::

Rather than repeating manual column-by-column calculations eight times, we define a concise helper function `calc_ci_table()` that computes the standard error and formats the 95% confidence interval `[lower - upper]` for any percentage matrix and row sample size vector:

```{r}
#| label: define-ci-helper

calc_ci_table <- function(pct_matrix, n_vector) {
  # pct_matrix: matrix of percentages (0-100)
  # n_vector: sample size per row
  se_matrix <- sqrt((pct_matrix * (100 - pct_matrix)) / n_vector)
  lower <- pmax(0, pct_matrix - 1.96 * se_matrix)
  upper <- pmin(100, pct_matrix + 1.96 * se_matrix)

  # Format as "[lower - upper]"
  formatted <- matrix(
    sprintf("[%.1f - %.1f]", lower, upper),
    nrow = nrow(pct_matrix),
    dimnames = dimnames(pct_matrix)
  )
  return(as.data.frame(formatted))
}
```

# Addressing Non-Random Response Bias & Missing Data (Post-Stratification Reweighting)

Confidence intervals and Chi-Square tests only account for **random sampling error**. In real-world social surveys, however, sample estimates can also be distorted by **non-random response bias** (systematic differential non-response across demographic groups) and **missing data**. For instance, younger adults and mobile renters are typically harder to contact and less likely to respond to household surveys than older, settled homeowners.

Two primary strategies exist to address missingness and non-response bias:

1. **Imputation or deletion** for item missingness (such as complete-case filtering when `NA` corresponds to structurally inapplicable respondents like children or retirees).
2. **Post-stratification survey reweighting** to correct for unit non-response and sample under-/over-representation relative to known population totals from census or official demographic registers.

::: {.callout-note}
## Post-Stratification Weighting Formula

Given an external population benchmark (here, the ONS Mid-Year Population Estimates `MYE_UK_wide`) across $G$ mutually exclusive age strata ($g = 1, \dots, G$), let:

- $\text{MYE\_Count}_g$: True population count in age group $g$.
- $\text{APS\_Count}_g$: Observed survey sample count in age group $g$.

The **grossing-up post-stratification weight** (or age count ratio) for each respondent in age group $g$ is:

$$w_g = \text{Age\_Count\_Ratio}_g = \frac{\text{MYE\_Count}_g}{\text{APS\_Count}_g}$$

Equivalently, a normalised relative weight is the ratio of the population proportion to the sample proportion: $w_g^{\text{rel}} = \frac{\text{MYE\_Pct}_g}{\text{APS\_Pct}_g}$. Applying $w_g$ scales the sample up to the total UK population while simultaneously correcting the age distribution so that weighted sample proportions exactly match ONS population benchmarks.
:::

## Deriving Age-Group Survey Weights (`Age_Count_Ratio`)

### Interpretation of Weighting Results

1. **Impact of Age Reweighting on Table 5 vs. Table 1:** In **Table 5**, most cells shift by more than $\pm 1$ percentage point relative to the unweighted **Table 1**. ## Looking Back / Methodological Reflection: `cut()` Boundary Behaviour (`include.lowest = TRUE`)

In R's base `cut()` function, intervals are **left-open and right-closed** `(a, b]` by default (`include.lowest = FALSE`). Because the tertile breaks of `Hhold_Size` are `c(1, 2, 3, 12)`:

- Calling `cut(Hhold_Size, breaks = c(1, 2, 3, 12), labels = c("Low", "Medium", "High"))` without `include.lowest = TRUE` defines the `Low` interval as `(1, 2]` (strictly greater than 1 and $\le 2$).
- As a result, all **single-person households (`Hhold_Size == 1`, $N = 11,427$)** fell on the left boundary and were converted to `NA`, leaving $N = 97,537$ observations ($36,753$ in `Low` [size 2], $25,712$ in `Medium` [size 3], and $35,072$ in `High` [size 4–12]).

Setting `include.lowest = TRUE` properly closes the lowest interval as `[1, 2]`, retaining all $11,427$ single-person households in the `Low` category ($N = 48,180$ in `Low`, total $N = 108,964$). We demonstrate below that including single-person households via `include.lowest = TRUE` preserves the exact same substantive conclusion:

```{r}

# Compare category counts without vs. with include.lowest = TRUE
```
