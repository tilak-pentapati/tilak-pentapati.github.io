1 Project Overview

According to the World Health Organization (WHO), stroke is the second leading cause of mortality globally, responsible for approximately 11\% of total deaths worldwide (over 6.6 million deaths annually)[cite: who2020stroke, feigin2021global]. Characterized by an acute focal neurological deficit resulting from vascular injury to the central nervous system—primarily ischemic cerebral infarction (87\%) or intracranial hemorrhage (13\%)—stroke is also a preeminent driver of chronic disability-adjusted life years (DALYs)[cite: boehme2017stroke].

Epidemiological evidence indicates that up to 80\% of premature strokes are preventable through early detection, clinical risk stratification, and targeted management of modifiable vascular risk factors, including hypertension, hyperglycemia, dyslipidemia, and smoking[cite: goldstein2011primary, wolf1991probability].

While traditional clinical risk tools like the Framingham Stroke Risk Profile (FSRP) rely on linear cox-proportional hazard regressions with fixed risk factors[cite: d1994stroke], modern machine learning (ML) architectures trained on Electronic Health Record (EHR) data offer opportunities to capture complex, non-linear interactions across multifaceted patient histories[cite: kuhn2013applied, steyerberg2010assessing].

3 Part 1: Data Cleaning, Factor Encoding & Missingness Mechanics

3.1 Factor Theory and Type Coercion in R

In statistical computing, transforming raw categorical data into R factor data structures is essential for both computational performance and statistical validity:

  1. Memory Optimization: Rather than storing redundant character strings across 5,110 rows, R factors store an integer vector combined with a single attribute containing distinct string levels.
  2. Preventing Mathematical Distortion: Storing categorical predictors (such as work_type or smoking_status) as numeric codes risks statistical routines misinterpreting nominal labels as continuous intervals.
  3. Contrast Encoding in Model Matrices: When building design matrices \mathbf{X}_{\text{model}} via model formulas (~ .), R dynamically converts K-level factors into K - 1 orthogonal dummy indicator variables relative to an established reference level[cite: kuhn2013applied].

In the raw CSV, missing BMI entries are recorded as "N/A" text strings, which forced read_csv() to parse the entire column as character. In addition, one isolated record contains gender == "Other", which constitutes a singleton factor level that causes cross-validation split failures. We resolve these issues below:

Code 
stroke_clean <- stroke_raw %>%
  # Remove administrative ID to eliminate target leakage
  select(-id) %>%
  mutate(
    # Recode "N/A" strings to true NA and cast to numeric
    bmi = na_if(bmi, "N/A"),
    bmi = as.numeric(bmi),
    
    # Recode singleton "Other" gender to NA
    gender = if_else(gender == "Other", NA_character_, gender),
    
    # Coerce categorical descriptors to factors
    gender = factor(gender),
    hypertension = factor(hypertension, levels = c(0, 1), labels = c("No", "Yes")),
    heart_disease = factor(heart_disease, levels = c(0, 1), labels = c("No", "Yes")),
    ever_married = factor(ever_married),
    work_type = factor(work_type),
    Residence_type = factor(Residence_type),
    smoking_status = factor(smoking_status),
    
    # Target variable: stroke (0 = No, 1 = Yes)
    stroke = factor(stroke, levels = c(0, 1), labels = c("No", "Yes"))
  ) %>%
  filter(!is.na(gender)) # Exclude singleton gender row

3.2 Missing Data Taxonomy: Imputation vs. Informative Missingness

Missing data represents a critical challenge in clinical biostatistics. According to Little and Rubin’s taxonomy[cite: little2019statistical], missingness falls into three classes:

  1. Missing Completely at Random (MCAR): Missingness is statistically independent of observed and unobserved data (\mathbb{P}(M \mid Y_{\text{obs}}, Y_{\text{mis}}) = \mathbb{P}(M)).
  2. Missing at Random (MAR): Missingness depends systematically on observed patient attributes, but given those attributes, is random (\mathbb{P}(M \mid Y_{\text{obs}}, Y_{\text{mis}}) = \mathbb{P}(M \mid Y_{\text{obs}})).
  3. Missing Not at Random (MNAR): Missingness depends directly on the unobserved variable itself (\mathbb{P}(M \mid Y_{\text{obs}}, Y_{\text{mis}}) \neq \mathbb{P}(M \mid Y_{\text{obs}})).

For bmi, exactly 201 values (3.93\%) are missing. Simple listwise deletion would discard 201 patient records, including 40 confirmed stroke cases (16\% of all positive cases in the dataset), introducing severe selection bias. Code 
# Conditional median imputation for BMI stratified by age deciles and biological sex
stroke_imputed <- stroke_clean %>%
  mutate(age_decile = cut(age, breaks = seq(0, 90, by = 10), include.lowest = TRUE)) %>%
  group_by(gender, age_decile) %>%
  mutate(bmi = if_else(is.na(bmi), median(bmi, na.rm = TRUE), bmi)) %>%
  ungroup() %>%
  # Fallback to global median if an age group is sparse
  mutate(bmi = if_else(is.na(bmi), median(bmi, na.rm = TRUE), bmi)) %>%
  select(-age_decile)

5 Part 3: Clinical Feature Engineering

Informed by clinical practice guidelines[cite: ada2023standards, boehme2017stroke], we engineer three domain-specific biomarkers:

  1. glucose_tier (ADA Criteria):
    • Normal: < 100 \text{ mg/dL}
    • Prediabetes: 100 - 125 \text{ mg/dL}
    • Diabetes: \ge 126 \text{ mg/dL}
  2. bmi_tier (WHO Criteria):
    • Underweight: < 18.5
    • Normal: 18.5 - 24.9
    • Overweight: 25.0 - 29.9
    • Obese: \ge 30.0
  3. cv_triad: A combined cardiovascular risk flag identifying patients with concurrent hypertension, heart disease, and age \ge 60 years.
Code 
stroke_features <- stroke_imputed %>%
  mutate(
    # Clinical glucose stratification
    glucose_tier = case_when(
      avg_glucose_level < 100 ~ "Normal",
      avg_glucose_level < 126 ~ "Prediabetes",
      TRUE ~ "Diabetes"
    ) %>% factor(levels = c("Normal", "Prediabetes", "Diabetes")),
    
    # WHO BMI stratification
    bmi_tier = case_when(
      bmi < 18.5 ~ "Underweight",
      bmi < 25.0 ~ "Normal",
      bmi < 30.0 ~ "Overweight",
      TRUE ~ "Obese"
    ) %>% factor(levels = c("Underweight", "Normal", "Overweight", "Obese")),
    
    # Cardiovascular Triad risk flag
    cv_triad = if_else(
      hypertension == "Yes" & heart_disease == "Yes" & age >= 60,
      "High_Risk", 
      "Standard"
    ) %>% factor(levels = c("Standard", "High_Risk"))
  )

6 Part 4: Imbalanced Learning & Tidymodels Pipeline (SMOTE)

6.1 The Accuracy Paradox

In this cohort, 4,860 out of 5,109 patients (95.13\%) are stroke-free. A trivial, zero-rule model that assigns stroke = No to every patient achieves 95.13\% accuracy while possessing a Sensitivity of 0\%[cite: he2009learning, kuhn2013applied].

Because the clinical cost of a False Negative vastly exceeds that of a False Positive (C_{FN} \gg C_{FP}), models must be formulated to optimize Sensitivity and AUC-ROC rather than raw accuracy[cite: fawcett2006introduction].

6.2 Synthetic Minority Over-sampling (SMOTE)

We employ SMOTE via the themis package[cite: chawla2002smote]. Rather than duplicating minority records, SMOTE synthesizes novel minority cases by identifying the K nearest neighbors for each minority instance \mathbf{x}_i \in S_{\text{min}} and interpolating in feature space:

\mathbf{x}_{\text{synthetic}} = \mathbf{x}_i + \lambda (\mathbf{x}_{zi} - \mathbf{x}_i), \quad \lambda \sim U(0, 1)

# Generate predicted class probabilities and class labels on test set
eval_model <- function(fitted_wf, model_label, test_df, thresh = 0.50) {
  probs <- predict(fitted_wf, new_data = test_df, type = "prob")
  
  df_res <- test_df %>%
    select(stroke) %>%
    bind_cols(probs) %>%
    mutate(
      .pred_class = factor(if_else(.pred_Yes >= thresh, "Yes", "No"), levels = c("No", "Yes")),
      Model = model_label,
      Threshold = thresh
    )
  
  # Calculate metrics using yardstick with event_level = "second" for "Yes"

8 Part 6: Clinical Decision Threshold Calibration (Youden’s J)

In clinical risk screening, setting the decision threshold to p = 0.50 is rarely optimal because event prevalence is low (4.9\%). Using the pROC package, we determine the optimal operating threshold via Youden’s J statistic, which maximizes the trade-off between sensitivity and specificity[cite: fawcett2006introduction]:

J = \max_p (\text{Sensitivity}(p) + \text{Specificity}(p) - 1)

10.1 Key Clinical Findings

  1. Age as the Primary Non-Modifiable Determinant: Consistent with the Global Burden of Disease Stroke Study[cite: feigin2021global], patient age is the single most powerful predictor of cerebrovascular events. Stroke incidence increases non-linearly past age 60, driven by progressive vascular stiffening, endothelial dysfunction, and subclinical atherosclerosis.
  2. Actionable Metabolic & Vascular Catalysts: Chronic hyperglycemia (> 126 \text{ mg/dL}) and diagnosed hypertension function as potent risk catalysts. Co-occurrence of hypertension and heart disease quadruples empirical stroke incidence.
  3. The Informative Value of EHR “Unknowns”: Retaining "Unknown" entries in smoking_status avoided the loss of over 30\% of the cohort while surfacing an important demographic signal: unrecorded smoking status frequently corresponds to younger patients with fewer healthcare encounters, exhibiting low baseline stroke rates.

10.2 Methodological Lessons in Medical Machine Learning

  • Abandoning Raw Classification Accuracy: In rare-event clinical epidemiology (4.9\% prevalence), standard accuracy is fundamentally flawed. Relying on default 0.50 thresholds in unweighted models yielded 95.2\% accuracy but missed 98\% of actual stroke events.
  • The Value of Synthetic Resampling (SMOTE): Incorporating SMOTE within a unified tidymodels pipeline elevated model sensitivity from 2.0\% to 78.0\%, enabling the classifier to capture subtle physiological signals across the minority class.
  • Explainability vs. Ensembles: While Random Forest and XGBoost models achieved competitive discrimination (\text{AUC} \approx 0.81 - 0.82), SMOTE-balanced Logistic Regression delivered equivalent performance (\text{AUC} = 0.83) while providing interpretable odds ratios that clinicians can review and understand at the bedside.

## Part 1: Data Cleaning, Factor Encoding & Missingness Mechanics

### Factor Theory and Type Coercion in R

In statistical computing, transforming raw categorical data into R `factor` data structures is essential for both computational performance and statistical validity:

1. **Memory Optimization:** Rather than storing redundant character strings across 5,110 rows, R factors store an integer vector combined with a single attribute containing distinct string `levels`.
2. **Preventing Mathematical Distortion:** Storing categorical predictors (such as `work_type` or `smoking_status`) as numeric codes risks statistical routines misinterpreting nominal labels as continuous intervals.
3. **Contrast Encoding in Model Matrices:** When building design matrices $\mathbf{X}_{\text{model}}$ via model formulas (`~ .`), R dynamically converts $K$-level factors into $K - 1$ orthogonal dummy indicator variables relative to an established reference level[cite: kuhn2013applied].

In the raw CSV, missing BMI entries are recorded as `"N/A"` text strings, which forced `read_csv()` to parse the entire column as character. In addition, one isolated record contains `gender == "Other"`, which constitutes a singleton factor level that causes cross-validation split failures. We resolve these issues below:

```{r clean-types}
stroke_clean <- stroke_raw %>%
  # Remove administrative ID to eliminate target leakage
  select(-id) %>%
  mutate(
    # Recode "N/A" strings to true NA and cast to numeric
    bmi = na_if(bmi, "N/A"),
    bmi = as.numeric(bmi),
    
    # Recode singleton "Other" gender to NA
    gender = if_else(gender == "Other", NA_character_, gender),
    
    # Coerce categorical descriptors to factors
    gender = factor(gender),
    hypertension = factor(hypertension, levels = c(0, 1), labels = c("No", "Yes")),
    heart_disease = factor(heart_disease, levels = c(0, 1), labels = c("No", "Yes")),
    ever_married = factor(ever_married),
    work_type = factor(work_type),
    Residence_type = factor(Residence_type),
    smoking_status = factor(smoking_status),
    
    # Target variable: stroke (0 = No, 1 = Yes)
    stroke = factor(stroke, levels = c(0, 1), labels = c("No", "Yes"))
  ) %>%
  filter(!is.na(gender)) # Exclude singleton gender row
```

### Missing Data Taxonomy: Imputation vs. Informative Missingness

Missing data represents a critical challenge in clinical biostatistics. According to Little and Rubin's taxonomy[cite: little2019statistical], missingness falls into three classes:

1. **Missing Completely at Random (MCAR):** Missingness is statistically independent of observed and unobserved data ($\mathbb{P}(M \mid Y_{\text{obs}}, Y_{\text{mis}}) = \mathbb{P}(M)$).
2. **Missing at Random (MAR):** Missingness depends systematically on observed patient attributes, but given those attributes, is random ($\mathbb{P}(M \mid Y_{\text{obs}}, Y_{\text{mis}}) = \mathbb{P}(M \mid Y_{\text{obs}})$).
3. **Missing Not at Random (MNAR):** Missingness depends directly on the unobserved variable itself ($\mathbb{P}(M \mid Y_{\text{obs}}, Y_{\text{mis}}) \neq \mathbb{P}(M \mid Y_{\text{obs}})$).


In `smoking_status`, $1,544$ records ($30.22\%$) are labeled `"Unknown"`. Pediatric patients and healthy young adults are rarely queried about smoking during routine care. By retaining `"Unknown"` as a **dedicated factor level**, the algorithm directly evaluates whether documentation omission correlates with stroke risk.

## Part 3: Clinical Feature Engineering

1. **`glucose_tier` (ADA Criteria):**
   - *Normal:* $< 100 \text{ mg/dL}$
   - *Prediabetes:* $100 - 125 \text{ mg/dL}$
   - *Diabetes:* $\ge 126 \text{ mg/dL}$
2. **`bmi_tier` (WHO Criteria):**
   - *Underweight:* $< 18.5$
   - *Normal:* $18.5 - 24.9$
   - *Overweight:* $25.0 - 29.9$
   - *Obese:* $\ge 30.0$
3. **`cv_triad`:** A combined cardiovascular risk flag identifying patients with concurrent hypertension, heart disease, and age $\ge 60$ years.


## Part 4: Imbalanced Learning & Tidymodels Pipeline (SMOTE)

### The Accuracy Paradox

In this cohort, $4,860$ out of $5,109$ patients ($95.13\%$) are stroke-free. A trivial, zero-rule model that assigns `stroke = No` to every patient achieves **$95.13\%$ accuracy** while possessing a **Sensitivity of $0\%$**[cite: he2009learning, kuhn2013applied].

Because the clinical cost of a False Negative vastly exceeds that of a False Positive ($C_{FN} \gg C_{FP}$), models must be formulated to optimize **Sensitivity** and **AUC-ROC** rather than raw accuracy[cite: fawcett2006introduction].

### Synthetic Minority Over-sampling (SMOTE)

We employ **SMOTE** via the `themis` package[cite: chawla2002smote]. Rather than duplicating minority records, SMOTE synthesizes novel minority cases by identifying the $K$ nearest neighbors for each minority instance $\mathbf{x}_i \in S_{\text{min}}$ and interpolating in feature space:

$$\mathbf{x}_{\text{synthetic}} = \mathbf{x}_i + \lambda (\mathbf{x}_{zi} - \mathbf{x}_i), \quad \lambda \sim U(0, 1)$$

### Stratified Partitioning & Recipe Construction


## Part 6: Clinical Decision Threshold Calibration (Youden's J)

In clinical risk screening, setting the decision threshold to $p = 0.50$ is rarely optimal because event prevalence is low ($4.9\%$). Using the `pROC` package, we determine the optimal operating threshold via **Youden's $J$ statistic**, which maximizes the trade-off between sensitivity and specificity[cite: fawcett2006introduction]:

$$J = \max_p (\text{Sensitivity}(p) + \text{Specificity}(p) - 1)$$

```{r threshold-calibration}
# Calculate optimal threshold using pROC
proc_obj <- roc(res_m2$results_df$stroke, res_m2$results_df$.pred_Yes, levels = c("No", "Yes"), direction = "<")
best_coords <- coords(proc_obj, "best", best.method = "youden", ret = c("threshold", "sensitivity", "specificity"))

kable(best_coords, digits = 3, caption = "Table 4: Optimal Decision Threshold via Youden's J Index") %>%
  kable_styling(bootstrap_options = c("striped", "hover"), full_width = FALSE)
```

By calibrating the decision threshold to **$p^* \approx 0.44$** on the SMOTE Logistic Regression model, the pipeline achieves **$80.0\%$ Sensitivity** and **$73.5\%$ Specificity**, successfully capturing 4 out of every 5 stroke patients in the held-out test cohort.

## Part 8: Epidemiological Findings & Methodological Takeaways

### Key Clinical Findings

1. **Age as the Primary Non-Modifiable Determinant:** Consistent with the Global Burden of Disease Stroke Study[cite: feigin2021global], patient age is the single most powerful predictor of cerebrovascular events. Stroke incidence increases non-linearly past age $60$, driven by progressive vascular stiffening, endothelial dysfunction, and subclinical atherosclerosis.
2. **Actionable Metabolic & Vascular Catalysts:** Chronic hyperglycemia ($> 126 \text{ mg/dL}$) and diagnosed hypertension function as potent risk catalysts. Co-occurrence of hypertension and heart disease quadruples empirical stroke incidence.
3. **The Informative Value of EHR "Unknowns":** Retaining `"Unknown"` entries in `smoking_status` avoided the loss of over $30\%$ of the cohort while surfacing an important demographic signal: unrecorded smoking status frequently corresponds to younger patients with fewer healthcare encounters, exhibiting low baseline stroke rates.

### Methodological Lessons in Medical Machine Learning

- **Abandoning Raw Classification Accuracy:** In rare-event clinical epidemiology ($4.9\%$ prevalence), standard accuracy is fundamentally flawed. Relying on default $0.50$ thresholds in unweighted models yielded $95.2\%$ accuracy but missed $98\%$ of actual stroke events.
- **The Value of Synthetic Resampling (SMOTE):** Incorporating SMOTE within a unified `tidymodels` pipeline elevated model sensitivity from $2.0\%$ to **$78.0\%$**, enabling the classifier to capture subtle physiological signals across the minority class.
- **Explainability vs. Ensembles:** While Random Forest and XGBoost models achieved competitive discrimination ($\text{AUC} \approx 0.81 - 0.82$), **SMOTE-balanced Logistic Regression** delivered equivalent performance ($\text{AUC} = 0.83$) while providing interpretable odds ratios that clinicians can review and understand at the bedside.
